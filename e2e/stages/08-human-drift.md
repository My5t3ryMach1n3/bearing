The rules apply to people too.

- [ ] Without an agent, open a PR that adds an ElastiCache Redis cluster to `infra/` "for search speed"
- [ ] The deployment check should flag a node the target doesn't have
- [ ] Add one AWS resource type Bearing doesn't map. It must be reported, not silently dropped
- [ ] Close the PR, or turn it into a change proposal if you think Redis is justified
