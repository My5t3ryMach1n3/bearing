# B-08 Implement `bearing context`

**Milestone:** M1 MVP (TypeScript) · Design loop  
**Labels:** area:agent  
**Depends on:** B-04, B-07

Give the agent exactly what it needs and no more.

- [ ] `bearing context --issues` prints open requirements, the C4 rules and DSL conventions
- [ ] `bearing context #<n>` prints the model slice an issue touches: components, paths, relationships, its dynamic view and criteria
- [ ] Output is plain text sized for an agent's context, with a `--json` option
