# AGENTS.md

Instructions for coding agents working in this repository.

## All changes go through a pull request

- Never commit or push directly to `main`. Every change, however small, lands through a pull request.
- Start each change on a new branch off the latest `main`, push it, and open a PR against `main`.
- Link the issue the PR works on with `Closes #N` in the PR description. Work is tracked in [GitHub issues](https://github.com/My5t3ryMach1n3/bearing/issues), not in files in the repo.
- Don't merge your own PR unless a human has asked you to.

- [Build plan](docs/build-plan.md): milestones, sequencing and open questions.
